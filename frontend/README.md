# SuperKart Sales Forecasting — Frontend

Streamlit dashboard that calls the SuperKart backend API to forecast
product sales revenue for any store-product combination.

## Features

- **Single Prediction** — fill in product & store details, get an instant forecast
- **Batch Prediction** — upload a CSV and download predictions for all rows

## Backend API

👉 [superkart-sales-api](https://huggingface.co/spaces/phaniaigeek/superkart-sales-api)
